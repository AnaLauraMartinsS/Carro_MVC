# CarroMVC

## Gerenciador de Veículos em Node.js com Arquitetura MVC  

Este é um projeto simples de uma aplicação web para gerenciamento de veículos, construída como parte de uma atividade de desenvolvimento web.  
O projeto segue a arquitetura **MVC (Model-View-Controller)** para separar as responsabilidades da aplicação, tornando-a mais organizada e fácil de manter.  

---

## ✨ Funcionalidades
- **Listagem de Veículos**: Visualize todos os veículos cadastrados em uma tabela organizada.  
- **Cadastro**: Adicione novos veículos com informações como nome, fabricante e data de lançamento.  
- **Edição**: Atualize os dados de veículos existentes.  
- **Exclusão**: Remova veículos da lista.  
- **Home Page**: Exibe o total de veículos cadastrados.  

---

## 💻 Tecnologias
- **Node.js**: Ambiente de execução JavaScript.  
- **Express**: Framework web para Node.js.  
- **EJS**: Engine de templates para renderizar as páginas HTML dinamicamente.  
- **HTML & CSS**: Para a estrutura e o estilo das páginas.

## 🚀 Como Executar o Projeto

### Pré-requisitos
Certifique-se de ter o **Node.js** e o **npm** (que vem com o Node.js) instalados em sua máquina.  

### Instalação
Clone este repositório:

- git clone [URL_DO_SEU_REPOSITORIO]

Navegue até o diretório do projeto:

- cd CarroMVC

Instale as dependências:

- npm install

### Execução

Inicie o servidor localmente:

- node app.js


Se você tiver o nodemon instalado, pode usar:

- nodemon app.js


O servidor será iniciado na porta 3000. Abra seu navegador e acesse:
http://localhost:3000
